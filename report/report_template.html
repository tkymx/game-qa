Jev vs Laya 対戦記録

Jev — TypeSafe AI のクラウド API Laya — Apple Silicon 上のローカル MLX

結論

同じ敵の出方で並べたプレイ

左が Jev、右が Laya。シードごとに敵の出現位置・種類が同じなので、動きの差がそのまま判断の差になる。

シード

測り方

  • 同じシード（1〜5）で Math.random を固定し、敵の出現位置・種類・発射タイミングを両エンジンで揃えた。各シードで Jev → Laya の順に実行。
  • アプリと同じく実ブラウザを表示した状態（headed）で実行。操作は仮想ジョイスティックのドラッグのみで、攻撃はゲーム側の自動攻撃。
  • 当たる向きはAIの選択肢から外し、近い敵からの離脱と中央への引き戻しはコード側のガードが担う。「ガード介入率」が高いほどエンジン差は薄まる。
  • 判定時間はランナーから見た往復時間。Jev は判断のたびに180ms待つ設定、Laya は待ちなしで連続判断。
  • 回数が少ないと、差が小さい指標は偶然の範囲と見たほうがいい。
